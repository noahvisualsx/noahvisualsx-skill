# 人物照片扩展：8张换动作提示词（双版本）+ 主题文案

用户发来人物照片，只说“扩展”“复刻”，或只发图不说话，都按这个流程。用户会上传参考图锁脸，所以脸部不细写。

## 1. 拆解参考图（只在心里做，不输出分析过程）

- 人物：年龄段（默认写成年人，20岁出头）、气质、表情状态
- 妆容和发型：妆感、眼妆颜色、唇妆，发色、长度、盘发/披发、刘海、碎发
- 服装：逐件写款式、颜色、面料、印花、领口、袖子、长度
- 配饰：发饰、耳饰、项链、手链、美甲、包、耳机等
- 道具：书、茶具、花、扇子等，只用参考图里出现过的或场景里合理存在的
- 场景：地点类型、背景元素、季节
- 光线：时间段、方向、硬光/柔光、逆光、有无闪光灯
- 质感：手机直拍、CCD、胶片、相机；饱和度、对比、颗粒、光晕、过曝
- 原图水印一律不写，提示词注明无文字无水印；画面里的文字写“文字自然模糊，不要乱码”

## 2. 设计8个动作

8张景别、机位、动作都要拉开，大致分配：
- 2张全身（一张动态：走、回头、转身；一张静态：站、倚靠）
- 2张七分身/半身（倚靠、坐、侧身、和道具互动）
- 1张低姿态或坐姿
- 2张特写（胸像看镜头；手部和配饰/道具入镜）
- 1张背影或过肩、前景遮挡、侧脸剪影这类氛围镜头
每张写清：景别、动作（双手分别在做什么）、视线、头部角度、机位高低、焦段、景深、主体在画面的位置。
动作自然，不刻意性感化。

## 3. 输出格式

依次输出两个代码块：

**Nano Banana Pro 版（中文）：**

```
参考上传图片：保持人物脸部五官、妆容、发型发色完全一致，不改脸、不网红化、不过度磨皮。一次性生成8张独立单图，[画幅，按原图比例]，不拼图、不九宫格、不分屏，无文字无水印。

统一设定：[人物年龄气质表情]。[妆容]。[发型]。[服装逐件]。[配饰]。[道具]。
场景：[场景]。
光线：[光线]。
质感：[质感]。8张保持同一人、同一天、同场景、同服装、同光线。

图1：……
……
图8：……
```

**GPT Image 2 版（英文）：** 内容与中文版一一对应，开头写清 Use the uploaded image as the face reference / keep facial features, makeup, hairstyle exactly the same / no beautification / Generate 8 separate standalone images, [ratio], no collage, no grid, no split screen, no text, no watermark；分段 Subject / Scene / Lighting / Look，再 Image 1 到 Image 8。

## 4. 主题文案

提示词后给2条，每条单独代码块：

```
主题：[4到8字，从画面元素里取意象]

[4到5行短句，第一人称，分行像小诗]
```

- 必须用到图里具体的东西（花名、物件、天气、场景细节），不写“美好”“治愈”“岁月静好”这类空词
- 带一点动作或转折，最后一行留余味
- 不用 emoji、话题标签、营销腔

## 5. 回复要求

- 用专业摄影语言写光线、镜头、机位、景深、色彩、质感
- 保留原图风格：原图真实就写真实手机/相机质感，原图胶片感就写胶片感，不要 CG 感
- 回复只有：中文提示词代码块 → 英文提示词代码块 → 两条文案代码块 → 最多一句提示（如“想换动作只改图1到图8”）。不输出分析过程。
- 用户只要文案时，只给文案。
