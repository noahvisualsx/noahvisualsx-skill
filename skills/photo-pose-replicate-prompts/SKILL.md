# 人物照片复刻 + 换动作提示词 + 主题文案

用户发来一张或几张人物照片，说“复刻这张图”“生成不同动作/姿势”，或者只发图不说话（默认就是要复刻换动作）时，按下面流程处理。换花、换物件这类换主体需求不用这个 skill。

## 1. 拆解参考图（只在心里做，不输出分析过程）

- 人物：年龄段、气质、表情状态。脸部不细写，用户会上传参考图锁脸
- 妆容和发型：美瞳颜色、妆感、痣等标志点，发色、长度、卷直、刘海
- 服装：逐件写清款式、颜色、面料、印花、领口、袖子、长度、配饰（帽子、项链、耳坠、手套、包、袜子、鞋、翅膀等）
- 道具：花束、包、书、鸽子等
- 场景：地点类型、背景元素（建筑、树、水面、招牌、电塔、风车等）、季节
- 光线：时间段、硬光还是软光、方向，有没有闪光灯
- 设备和质感：手机直拍、超广角/鱼眼、CCD 卡片机、相机，饱和度、颗粒、过曝
- 多张参考图里有不一致的地方（如帽子不同），选一个统一，保证4张一致
- 原图有水印（抖音号、小红书号等）一律不写进提示词，并在提示词里写“无文字无水印”

## 2. 设计4个动作

4张图的景别、机位、动作都要拉开差异，常用组合：
- 一张全身动态（走路、奔跑、转圈、跳跃、裙摆飞起、甩头发）
- 一张半身或七分身静态（倚靠、扶帽、插兜、侧身、坐）
- 一张低姿态（蹲、坐、躺在地上）
- 一张特写（胸像、回头、看镜头、手部和道具入镜）
每张写清：景别、具体动作（双手分别在做什么）、视线方向、头部角度、机位高低、焦段、景深、主体在画面位置。

## 3. 提示词格式

放在一个代码块里，方便直接复制：

```
参考上传图片：保持人物脸部五官、妆容、发型发色完全一致，不改脸、不网红化、不过度磨皮。一次性生成4张独立单图，[画幅]，不拼图、不九宫格、不分屏，无文字无水印。

统一设定：[人物年龄气质表情]。[发型]。[服装和配饰逐件描述]。[道具]。
场景：[场景描述]。
光线：[光线描述]。
质感：[设备和色调质感]。4张保持同一人、同一天、同场景、同服装、同光线。

图1：[景别]，[动作]，[视线]，[机位]，[焦段]，[构图]。
图2：……
图3：……
图4：……
```

## 4. 主题和文案

提示词后面紧跟着给发帖用的主题和文案，默认2条，每条单独一个代码块：

```
主题：[4到8个字，有画面感]

[4到5行短句诗意文案]
```

写法要求：
- 主题短、有意象，从画面里取元素（花名、季节、天气、场景物件），比如“风车停在六月”“杏花信”“不着陆”
- 文案4到5行，每行短，分行像小诗，第一人称
- 必须用到图里具体的东西（雏菊、缎带、风车、白鸽、电线杆、湖、裙摆、翅膀），不写空泛的“美好”“治愈”“岁月静好”
- 带一点动作或转折，最后一行留余味
- 不用 emoji，不用话题标签，不写营销腔
- 用户只要文案时，就只给主题文案，不给提示词

## 5. 写作要求

- 用专业摄影语言写光线、镜头、机位、景深、色彩、质感，不只堆形容词。
- 默认保留参考图原本的妆感和风格；参考图偏真实就写真实手机/相机质感，不要 CG 感。
- 人物默认写成成年人，动作自然，不刻意性感化。
- 招牌等文字写“文字自然模糊，不要乱码”。
- 回复简短：提示词代码块 → 主题文案代码块，最多一句提示（比如想换动作只改“图1到图4”那几行）。不输出分析过程。
