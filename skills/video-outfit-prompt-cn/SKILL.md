# 穿搭拆解 → GPT 生图提示词

用户发来一段穿搭视频（OOTD、换装、街拍、试穿带货），或者直接发一张穿搭照片，想让自己的原创角色穿上同款。在 GPT 里她会先传人物母图（角色的定妆脸），再传服装参考图。你的活：把这套衣服拆清楚，写一条提示词，让 GPT 从参考图2提取衣服，穿到参考图1的人物身上。

**衣服以图为准，文字只负责盯住最容易画错的几处。**她验证过：只靠文字描述，GPT 还原出来的衣服总是对不上。所以一定要有服装参考图，提示词里写明以图为准。

默认生图模型：ChatGPT Image（自然语言，不用权重括号语法）。她说用即梦 / Seedream / Nano Banana 时同样适用。

母图不一定发给你。发了就顺带看一眼发型发色，避免穿搭和发型风格打架；没发就照常写，提示词里用「参考图1」指代。

---

## 1. 两种输入

**直接发照片或截图：**不抽帧也不裁图，拆完直接写提示词就行。她会自己把这张原照片当参考图2上传。照片里露出来的脸、口罩、头发、手机、贴纸，都要在提示词的参考图说明里点名「不取」。

**发视频：**挑一帧做成服装参考图，用 SendUserFile 发给她，再写提示词。做法见第 2 节。

**只给了抖音 / 小红书 / X 链接：**工作区下载不了，直接让她发视频文件或截图，不要反复尝试下载。

---

## 2. 视频：做服装参考图

**先看全：**抽帧拼联系表，看有几套衣服、各在什么时间段。不要只看前几帧，换装视频的衣服在后面。

```bash
ffprobe -v error -show_entries format=duration -of csv=p=0 input.mp4
mkdir -p frames
# 按镜头切换抽帧：换装视频基本一套衣服对应一次切换
ffmpeg -loglevel error -i input.mp4 -vf "select='gt(scene,0.3)'" -fps_mode vfr frames/scene_%03d.jpg
# 均匀补抽：每秒 1 帧，超过 60 秒改 fps=0.5
ffmpeg -loglevel error -i input.mp4 -vf fps=1 frames/t_%03d.jpg
ffmpeg -loglevel error -i frames/t_%03d.jpg -vf "scale=240:-1,tile=7x4" frames/sheet_%02d.jpg
```

老版本 ffmpeg 不认 `-fps_mode` 就换成 `-vsync vfr`。

**再挑清楚的一帧：**在这套衣服出现的时间段里密抽（每秒 4 帧），按清晰度排序。

```bash
mkdir -p hf && ffmpeg -loglevel error -ss <开始秒> -to <结束秒> -i input.mp4 -vf fps=4 -q:v 1 hf/f_%03d.jpg
```

```python
# 边缘方差越大，画面越清晰；只算画面中间衣服所在的区域
import glob
from PIL import Image, ImageFilter, ImageStat
r = []
for p in sorted(glob.glob("hf/*.jpg")):
    im = Image.open(p).convert("L"); w, h = im.size
    e = im.crop((int(w*.14), int(h*.2), int(w*.86), int(h*.86))).filter(ImageFilter.FIND_EDGES)
    r.append((ImageStat.Stat(e).var[0], p))
for v, p in sorted(r, reverse=True)[:12]: print(round(v), p)
```

再拼一张带帧号的联系表对照着看：

```python
import glob
from PIL import Image, ImageDraw
ps = sorted(glob.glob("hf/*.jpg"))[:40]
W = Image.new("RGB", (180*10, 340*((len(ps)+9)//10)), "white"); d = ImageDraw.Draw(W)
for k, p in enumerate(ps):
    x, y = (k % 10)*180, (k//10)*340
    W.paste(Image.open(p).resize((180, 320)), (x, y+20)); d.text((x+5, y+3), p.split("/")[-1], fill="black")
W.save("hf_sheet.jpg")
```

**挑帧标准：**正面或微侧；整套从领口到裙摆或裤脚完整入镜；手臂不挡住衣服的关键结构；没有动作模糊；贴纸没有压在衣服上。在清晰度排名靠前的帧里，挑最符合这几条的一张。

**裁图：**从下巴（或口罩下沿）往下裁，把脸彻底去掉，但要留住脖子上的挂脖带、项链这些细节。平台水印、账号名、贴纸也一起裁掉。视频帧里博主的脸会把生成的脸带偏，视觉信息永远压过文字，写多少遍「不要这张脸」都没用。

```python
from PIL import Image
im = Image.open("hf/f_039.jpg")
im.crop((0, 188, 700, 1262)).save("/mnt/user-data/outputs/服装参考图_<款式>.jpg", quality=97)  # 坐标先看图再定
```

裁完用 Read 看一眼，确认脸、水印、贴纸都没了，衣服完整，再用 SendUserFile 发给她。视频里有几套衣服，就每套各做一张。

## 3. 拆解

有几套就拆几套，按出现顺序编号 Look 1 / Look 2，视频附大概时间点。超过 3 套时，先列一行一套的简表让她挑，不要一口气全写。

每套按「外 → 内、上 → 下、再到鞋包配饰」的顺序，每件衣服都按下表过一遍：

| 项 | 写到什么程度 |
|---|---|
| 品类 | 写具体名字：短款机车夹克、V领开衫、直筒牛仔裤、百褶迷你裙。不写「上衣」「裤子」 |
| 版型 | oversize / 合身 / 修身 / 直筒 / A字 / 阔腿；oversize 要写多宽（肩线落在大臂中段） |
| 长度落点 | 下摆落在腰线 / 胯骨 / 大腿中段 / 膝上几厘米 / 脚踝。这是比例的关键，必写 |
| 领 · 袖 · 门襟 | 一字领 / 挂脖 / 交叉裹身 / 翻领，蝙蝠袖 / 落肩袖 / 泡泡袖，单排几粒扣、拉链 |
| 面料质感 | 粗针织、细罗纹、马海毛、弹力棉、水洗牛仔、哑光皮、雪纺、缎面、蕾丝、灯芯绒 |
| 颜色 | 具体色名 + 饱和度明度：浅芭蕾粉、巧克力棕、奶油白、低饱和雾霾蓝、炭灰。不写「浅色」「深色」 |
| 图案工艺 | 波点大小与配色、条纹宽窄与方向、格纹配色、刺绣、做旧、破洞位置 |
| 细节 | 纽扣与按扣、抽绳抽褶、开衩、口袋、系带、腰带 |
| 穿法 | 前半塞、卷袖、露肩、敞开不扣、内搭从下摆露出一截、裤脚堆叠 |

鞋、包、配饰同样写 品类 + 颜色 + 材质 + 大小（例：黑色哑光皮乐福鞋配白色中筒袜；小号银色金属链条腋下包）。

**发型妆容：**默认不从视频或照片里拿，跟着母图走（她的角色有固定发型发色）。她说「发型也照这个」时才拆。

**颜色校正：**视频和照片普遍带滤镜、白平衡偏暖。看画面里白色的东西偏成了什么色，反推回去，按中性日光下的颜色写。实在拿不准就写成范围（「米白到浅燕麦之间」），并在清单里标出来。

**品牌：**认得出品牌也不复刻 logo、字母印花、标志性老花，一律写「无logo」，或者用同风格的抽象设计代替。

**画面里没拍到的部分**（多半是鞋）：按整套风格补一个，在清单里标「（补）」，提示词里写明「参考图2里没有，补充」。

## 4. 给她看的拆解清单

提示词之前先给一份很短的清单，方便她一眼核对：每套 4–6 行，一行一件，只写结论不解释。看不到、靠猜补的项标「（补）」。

---

## 5. 写提示词

顺序决定权重，越往后越容易被模型忽略，所以严格按下面的顺序写。全长控制在 800–1200 字，超过 1500 字会明显掉指令。默认一次 6 张，她的习惯范围是 4–8 张；每张独立成图，画面随机不重样，不要拼图。

```
【参考图】
参考图1 = 人物母图：只取脸、五官骨相、发色与发型。
参考图2 = 服装参考图：完整提取图中的整套衣服，包括<逐件点名>，原样穿到参考图1的人物身上。只取衣服，参考图2里的<脸 / 口罩 / 头发 / 手机>、身材、姿势、背景、光线、滤镜一律不取。
【优先级】脸和发型 → 只看参考图1；衣服 → 只看参考图2，以图为准，一比一还原款式、颜色、面料、长度和穿法，不重新设计，不增减任何元素。

【脸部铁律】
脸是全图唯一不可改动的元素，画面中的脸必须来自参考图1。妆容与造型只能覆盖在参考图1原有的五官结构之上，不允许改变脸型宽窄、下颌线、下巴长度与尖度、眼睛形状与大小、眼距、鼻梁高度、鼻翼宽度、嘴巴大小、上下唇比例、年龄感。不要放大眼睛，不要削尖下巴，不要幼态娃娃脸。造型与脸冲突时，一律以脸为准。

【身材比例】
头身比不低于1:7.5，腰线在肋骨下缘的高腰位置。全身照相机放低到膝盖高度，等效85mm中长焦，不要俯拍，不要广角贴近拍。站姿一脚略前一脚略后，重心在后腿。

【这组照片】
一次生成6张，每张都是独立完整的一张照片，不要拼图、不要多宫格。同一个人、同一天、同一套穿搭。
景别与动作随机且互不重复，在这些里自由组合：<全身OOTD、对镜自拍、走动抓拍、侧身回头、坐着的中景、某个细节的半身特写>。
至少两张是包含鞋子的完整全身。每张里的衣服必须和参考图2完全一致，只允许因视角产生正常变化。

【衣服还原要点】以参考图2为准，以下几处最容易画错，逐项核对：
1. ……（最有辨识度的结构：露肩方式、交叉裹身、挂脖、抽褶，并写一句「不是 ××」，防止被画成普通款）
2. ……（长度落点、腰线位置、内外层的叠穿关系）
3. ……（面料：软塌还是挺括，透不透）
4. ……（小细节：按扣、系带、开衩、波点）
5. 几种颜色分开，不要互相染色。
6. 配饰：……
7. 鞋（参考图2里没有时写「补充」）：……

【妆发】
发型发色跟随参考图1。妆容……（克制，只写怎么画在这张脸上，不写脸应该长什么样）

【场景与光线】
……（默认贴近原视频或原照片的场景气质：街边 / 商场 / 咖啡店 / 室内对镜；她指定就用她的）
人物自然接受现场光与色温，面料受光真实，不要棚拍光贴在背景上的抠图感。

【影调】
真实相机直出质感，自然肤色与皮肤纹理，不过度磨皮，衣服颜色还原准确，不加重滤镜。

【禁止】
AI塑料脸、放大眼睛、幼态娃娃脸、擅自改款、<点名最可能被画成的错误款式>、新增图案或logo、颜色跑偏、面料塑料感、衣服没有自然褶皱、头身比失调、腿短、广角畸变、藏手断手、错误手指、口罩与贴纸、水印与界面元素、拼图与多宫格。
```

**关键提醒：**提示词里不要出现任何对脸的正面形容，比如「精致的东亚女生」。这等于邀请模型重画脸。

## 6. 翻车补救

她发结果说哪里不对时，只给一句局部修改的指令，不要整条重写。

| 症状 | 补一句 |
|---|---|
| 衣服被重新设计、多了图案或logo | 「严格按参考图2还原，不允许新增任何图案、印花、logo、拼接或装饰」，并点名多出来的东西 |
| 颜色偏暖发黄、两件颜色串了 | 「在中性日光下呈现[色名]，[A]和[B]颜色分开，不要互相染色」 |
| oversize 变修身，或反过来 | 写尺寸感：「肩线落在大臂中段，衣身比身体宽出一拳」 |
| 长度不对 | 写落点：「下摆刚好落在胯骨上方」 |
| 露肩、叠穿这类穿法丢了 | 把这一条挪到【衣服还原要点】第 1 条 |
| 鞋没出现 | 「这张必须从头到脚完整入镜，鞋子清晰可见」 |
| 面料像塑料 | 「真实针织纹理，自然垂坠与褶皱」 |
| 脸变成了参考图2里人物的脸 | 原照片露脸了：截掉头部重新传，或者用裁头版 |
| 戴上了口罩，或者头发变成参考图2的 | 在参考图说明和禁止清单里都点名这一项 |
| 脸漂了 | 删掉所有对脸的形容词，脸部铁律保持在参考图说明之后第一段 |

## 输出规范

- 视频：先发服装参考图，再给拆解清单（短），最后给提示词。
- 照片：先给拆解清单（短），再给提示词。
- 提示词放在代码框里，一条完整，可以直接粘贴；前面说一句上传顺序：先传母图，再传服装图。
- 多套衣服：一套一条提示词，各自放在独立的代码框里。
- 不解释写法，不追问要不要别的版本。只有缺画面，或者拿不准她要哪套时才问。
- 她说「完整版」时，把所有修正合并进一条完整的提示词，不给片段让她自己拼。
