# 视频拆解与复刻提示词

用户上传一个视频（通常是抖音/小红书竖屏人物短视频），不需要额外说明，直接开始拆解并输出整套复刻提示词。用户会另外上传人物参考图来锁定脸部。

## 1. 抽帧分析

每个视频放在 scratchpad 下单独的新目录里，先复制一份再处理，不改原文件。

```bash
D=<scratchpad>/vN && mkdir -p $D && cp "<上传路径>" $D/in.mp4 && cd $D
# 元数据：时长、分辨率、帧率、有没有音轨
ffprobe -v error -show_entries format=duration:stream=codec_type,width,height,r_frame_rate -of compact in.mp4
# 检测剪辑点（没有输出就是一镜到底）
ffmpeg -v error -i in.mp4 -vf "select='gt(scene,0.25)',showinfo" -vsync vfr -f null - 2>&1 | grep -o "pts_time:[0-9.]*"
# 首帧大图：看发型、服装、场景、光线细节
ffmpeg -v error -ss 0.3 -i in.mp4 -frames:v 1 -vf scale=576:-1 f0.jpg
# 每 0.25 秒一帧、带时间戳的拼图：用来排动作时间线
ffmpeg -v error -i in.mp4 -vf "fps=4,scale=192:-1,drawtext=text='%{pts\:hms}':x=4:y=4:fontsize=16:fontcolor=red,tile=10x6" -frames:v 1 sheet4.jpg
# 关键动作帧并排放大（时间点从拼图里挑）
for t in 1.6 3.8 6.0; do ffmpeg -v error -ss $t -i in.mp4 -frames:v 1 -vf scale=280:-1 k_$t.jpg; done
ffmpeg -v error -i k_1.6.jpg -i k_3.8.jpg -i k_6.0.jpg -filter_complex hstack=3 keys.jpg
```

视频超过 15 秒时，把 tile 的行数调大，或者分两张拼图。用 Read 看 f0.jpg、sheet4.jpg 和 keys.jpg。

## 2. 需要拆出来的内容

- 基础信息：时长、画幅、是否一镜到底、视频类型（手势舞、律动、睡醒自拍等）
- 机位：手持还是固定、前置还是后置、景别（大特写、近景、腰部以上中景）、俯仰角度、焦段感、中途有没有拉远推近或者人物走位
- **发型（重点，要写到能直接复刻）**：颜色和冷暖、长度（到哪里）、直发还是卷发、卷在哪一段、分缝位置、刘海类型以及刘海遮住了哪里、碎发和蓬松度、头发垂在哪一侧、整齐还是凌乱、发质（顺滑、毛躁、一缕一缕）
- 妆面状态（写风格，不写五官）：素颜感还是韩系妆、腮红位置、唇色、眼周
- 服装：款式、颜色、面料、领口、纽扣和印花细节、袖长；前置镜头拍出来的字母是镜像的
- 美甲、配饰
- 场景：每样物件在画面里的位置，墙面、床、窗帘、家具
- 光线：光源位置、色温、高调还是暖调、有没有轮廓光、是否过曝
- 动作时间线：精确到 0.2–0.5 秒，左右一律按画面方向标，写清楚手型（剪刀手、敬礼、托腮、交叉手腕、绕小臂等）、头部动作和表情变化

## 3. 输出格式

用自然口语化的中文，简短。开头一段说明：时长、画幅、一镜到底与否、视频类型和看点。只有动作复杂、文字难以准确复刻时，才用一句话建议改用动作控制（可灵动作控制、即梦 Seedance 2.0 视频参考、Wan Animate），拿原视频当动作参考。

下面所有可复制的提示词都放在代码块里。

**首帧图**（上传人物参考图）代码块，按这个顺序写：
1. 固定开头：「保持参考图人物的脸部特征完全不变，只保留脸，发型不沿用参考图，严格按下面的描述生成。不网红化，不磨皮，保留皮肤纹理。」不描写五官。
2. 发型：单独写一段，写得最细
3. 妆面状态 → 服装 → 场景 → 光线（含色温）→ 镜头（前置还是后置、焦段、距离、构图范围、俯仰）→ 表情
4. 固定结尾：「生成4张独立单图，不拼图，不做九宫格。四张保持同一人、同发型、同服装、同场景、同光线，只在头部角度和表情上做细微变化。」

**图生视频提示词**代码块：
- 开头一段：画幅、机位、一镜到底、晃动情况、全程保持脸部、发型、服装、场景、光线一致、整体氛围和节奏
- 「动作时间线（左右均按画面方向）：」逐段写「起止秒：动作」
- 结尾一段：发丝和面料的动态、手指正确、光线和画质

**负面提示词**代码块，通用部分：多余的手指，手指融合，手部畸形，手臂穿模，脸部变形，五官漂移，换脸，过度磨皮，塑料皮肤，网红脸，服装变化，发型变化，背景变化，镜头推拉摇移（手持类视频改成：剪辑切换），字幕，水印，画面闪烁，慢动作。再根据视频补针对性的词，比如凌乱发型加「整齐顺滑的头发，卷发」，纽扣多的衣服加「纽扣数量错乱」。

最后写一两句实操提醒：时长或分段设置（超过 10 秒建议按动作节点拆成两段），以及最容易翻车的时间点或首帧要先检查的地方（比如手指、转场、发型的乱度）。不要写总结，结尾不要问还需不需要帮忙。
