# image-prompt-master

收到任何生图需求（发图说“扩展/复刻/换背景”，或者只说“帮我出一组 XX 风格的图”）都走这个流程：先让用户选，再写提示词。

第一条回复只做一件事：出选项让用户选。没选之前不写任何提示词，也不按默认值先出一版。只有用户消息里已经把模式、模型、比例、数量全说清楚了，才跳过选择直接写。

## 一、交互：先让用户选

### 怎么出选项（按顺序看当前环境有什么）
1. 有选项卡工具就用：AskUserQuestion，或者名字里带 ask_user / user_input / question 的提问工具（不同客户端叫法不同）。
2. 没有任何选项卡工具（claude.ai 网页聊天、手机 App 常见）：用文字列出编号选项，然后停下来等用户回复，这一条不写提示词。格式：

```
先选一下哦，回数字就行，比如 1A 2A 3B 4A，直接回“默认”就按推荐来：
1. 模式：A 原创生成（推荐） B 复刻（另传人物图只取脸） C 扩展（同一个人延展） D 编辑类
2. 模型：A Nano Banana Pro + GPT Image 2（推荐） B Midjourney C Seedream 5.0 D Grok Imagine（可多选）
3. 比例：A 3:4（推荐） B 9:16 C 1:1 D 16:9
4. 数量：A 8 张（推荐） B 4 张 C 1 张
也可以直接打字说别的
```
推荐项按用户消息内容判断放 A 位（比如发了一张图说扩展，模式就不列；编辑类数量推荐 1 张）。

3. 用户回“默认”“直接写”“随便”，或者回复里没回答某一项，就按默认值写，开头一句说明用了哪些默认值。

### 规则
- 一轮最多 4 题，每题 2–4 个选项，推荐项放第一个并标“（推荐）”。选项卡自带“其他”可手填，不用自己加；文字选项末尾写一句“也可以直接打字说别的”。
- 用户消息里已经说清楚的项直接跳过：说了“扩展”就不问模式，说了“MJ”就不问模型，说了“9:16”“出 4 张”同理。
- 默认值：模型 Nano Banana Pro + GPT Image 2；比例 3:4；数量 8 张（编辑类默认 1 张）；模式按消息判断（有一张人物图且说“扩展”或没说 = 扩展；有两张以上并说“复刻”= 复刻；没图 = 原创）。

### 第一轮
1. 模式（单选）：原创生成 / 复刻（另传人物图，只取脸）/ 扩展（基于原图同一个人延展）/ 编辑类（扩图、修复、换背景、换装，选后进第二轮）
2. 模型（多选）：Nano Banana Pro + GPT Image 2（推荐）/ Midjourney / Seedream 5.0 / Grok Imagine
3. 比例（单选）：3:4（推荐）/ 9:16 / 1:1 / 16:9
4. 数量（单选）：8 张独立单图（推荐）/ 4 张 / 1 张

电商、多参考图合成、动作复刻、风格复刻不在第一轮选项里：用户手填“其他”或消息里提到（主图、详情页、按这个姿势、学这个色调）时直接进入对应模式。

### 第二轮（只在需要时问，同样最多 4 题，没有选项卡工具时同样用文字编号选项）
- 选了编辑类：问具体操作（扩图 / 修复瑕疵 / 换背景 / 换装）。选扩图再问方向（四周均匀（推荐）/ 向上 / 向下 / 左右）和目标比例（16:9 / 9:16 / 4:3 / 1:1）。
- 有参考图且用途不明：每张图各一题，问它负责什么（多选：只取脸 / 背景场景 / 姿势动作 / 服装 / 风格色调）。超过 4 张图就先问前 4 张，其余按内容判断并在开头说明。
- 原创生成且没给风格：给 4 个差异大的风格方向（从第五节挑，按用户主题选最搭的 4 个，第一个标推荐）。

合并：第一轮跳过的题空出位置时，把第二轮要问的题提前放进同一张卡（总数仍不超过 4 题），能一轮问完就不弹两轮。

选完严格按选择写：选了哪个模型就只出哪个模型的写法，比例写进提示词（MJ 用 --ar），数量就是条数。

## 二、固定输出规则

- 每张图一条提示词，每条单独一个代码块。8 张就是 8 个代码块；两个模型就是每个模型各 8 个，先出完 Nano Banana Pro 版，再出 GPT Image 2 版，用小标题分开。
- 每条都是完整独立的，统一设定（人物、服装、场景、光线）在每条里重复写全，用户复制任意一条都能单独用。
- 每条都写“独立单图”，不拼图、不九宫格、不分屏，无文字无水印（电商需要文字时除外）。
- 有参考图锁脸时只写“保持参考图人物面部特征不变”，不描写五官、脸型、眼睛。
- 同一组图：同一人、同一天、同场景、同服装、同光线，只改动作、角度、表情、构图。8 张之间景别和机位拉开：全身动态、全身静态、七分身、半身、低姿态（蹲/坐）、特写、背影或侧身、环境大景，按需取。
- 摄影语言写全：人物年龄气质、发型、服装逐件、动作（双手各在做什么、视线、头部角度）、场景前中后景、光线（光源、方向、软硬、色温）、镜头焦段和机位、景深、色彩、质感。不堆“绝美”“高级感”这类空形容词。
- 默认偏真实：真实手机摄影或相机直出，自然光，皮肤保留纹理和毛孔，不网红化，不过度磨皮，没有塑料感，不做电影调色（用户要电影感时除外）。
- 提示词里不出现直角引号「」『』，需要引号一律用双引号 ""。
- 代码块前只写两三句设计思路（这组图的主线、8 张怎么分配），不写长解释，不输出分析过程。
- 结尾可以加一句上传顺序提醒（比如：先传你的人物图，再传原图），别的不加。

## 三、各模式怎么写

### 1. 原创生成（没有参考图）
- 风格用户定了就按用户的；没定就用第二轮选的方向。
- 先在心里定统一设定：人物（年龄、气质、发型、妆感）、服装逐件、场景、时间和光线、器材和质感，再分配 8 张的动作和机位。
- 没有参考图时可以写人物的整体样貌（气质、发型、肤色质感），但仍然不要网红脸，写“自然真实的普通人长相”。

### 2. 扩展（基于原图，同一个人）
- 图1 就是用户发的原图。拆解原图：人物气质、发型、妆容、服装逐件、配饰、场景元素、光线方向和色温、拍摄设备和质感。
- 提示词：以图1为参考，保持人物面部特征、发型、妆容、服装配饰、场景、光线、色调和画质完全一致，只改变动作、机位、景别和表情。
- 原图水印、平台 ID 一律不写进去。
- 不要和复刻混：扩展没有第二张人物图，脸和造型都来自同一张原图。

### 3. 复刻（用户另传自己的人物图，只取脸）
- 上传顺序固定：Image 1 = 用户自己的人物图，只取脸；Image 2 = 要复刻的原图，取造型（发型、妆容、服装、配饰）、场景、光线、构图、色调、质感。
- 明确写：只使用 Image 1 的面部特征，不使用 Image 1 的发型、服装、背景、光线；不使用 Image 2 人物的脸。
- 数量多于 1 张时：第 1 张一比一复刻原图的构图、动作和机位；其余在同造型同场景同光线下换动作和机位。
- 比例：用户选的比例写进提示词，并写“按指定比例输出，不跟随参考图比例”（Nano Banana 默认跟最后一张图的比例）。

### 4. 多参考图合成
- 每张图编号，每张只负责一件事，写清“只取什么、不取什么”。例：Image 1 只取脸；Image 2 只取背景场景，不取其中的人；Image 3 只取姿势动作和机位，不取脸、服装和背景；Image 4 只取服装，保留面料、图案、版型。
- 合成要求：人物放进背景时，光线方向和色温跟背景一致，有接触阴影，人物比例符合透视。
- 动作用文字再描一遍做保险（双手、双脚、身体朝向、头部角度）。
- 数量上限：GPT Image 2 最多 10 张参考图；Nano Banana Pro 总共最多 14 张，其中人物最多 5 张、物体最多 6 张、风格最多 3 张；Seedream 5.0 最多 14 张且参考图数加生成数不超过 15；MJ --edit 最多 4 张；Grok 编辑最多 5 张（部分第三方工具只开 3 张）。超了就提醒用户合并或删减。

### 5. 动作/姿势复刻
- 只取参考图的身体姿势、手位、头部角度、拍摄机位和景别；人物、服装、场景、光线按用户要求或用户另传的图。
- 多张时：第 1 张完全照参考图动作，其余做这个动作的前后瞬间或换机位。

### 6. 风格复刻
- 只学参考图的色调、光线、颗粒、质感、构图节奏，不取里面的人、物和具体场景。
- 把学到的风格写成具体参数：色温、反差、饱和度、阴影色倾向、颗粒大小、器材（CCD、胶片型号、手机直闪）、构图习惯（居中、留白、低机位）。这样换模型也能复现，不只依赖参考图。

### 7. 编辑类
固定三段式：要改什么 → 怎么改（新内容的样子、光线和透视怎么接） → 保持什么不变，最后加“除以上修改外，其他内容不要改变”。
- 扩图：先写画布变化（把画布扩展到 16:9，向左右延展 / 向下延展出全身），再写延展部分的内容（背景元素自然延续，光线方向、色温、机位距离、景深、颗粒一致），最后写原图主体、姿势、构图、颜色完全不变，延展边缘无接缝。扩幅大时提醒用户分两到三轮扩，每轮约 30–50%。
- 修复瑕疵：点名要修的东西（脸上的痘印、背景路人、电线、衣服褶皱、过曝高光），修完要自然，保留皮肤纹理，不磨皮不美白不瘦脸。
- 换背景：新背景具体到地点、时间、光线；写人物边缘自然、光线色温和新背景匹配、加接触阴影；人物脸、发型、服装、姿势不变。
- 换装：新衣服逐件写款式面料颜色；写合身、有自然褶皱、光影跟原图一致；脸、发型、姿势、背景不变。

### 8. 电商视觉
先想三件事再写画面：卖点是什么、目标用户 1 秒内要看懂什么、这张图是主图（拼点击率）还是详情页（拼理解成本）。
- 主图：产品占画面 60–70%，单一视觉焦点，背景干净或轻场景，一个卖点视觉化放大（质地、使用效果、尺寸对比、前后对比），1:1 优先。
- 场景图：产品放进真实使用场景，人物只做陪衬，视线和手的方向引向产品。
- 卖点图：用微距、剖面、水花、对比、成分实物来“演”卖点。
- 产品参考图：外形、比例、颜色、logo、包装文字完全不变，不重新设计。
- 需要文字时：每段文字放双引号，写位置、字体风格和层级（主标题 / 副标题 / 价格 / 小字），写“每段只出现一次”。
- 8 张默认分配：主图 2 张（不同构图）、场景 2 张、卖点特写 2 张、细节 1 张、尺寸或使用对比 1 张。

## 四、各模型写法

### Nano Banana Pro
- 自然语言完整段落，像给摄影师的 brief。中文或英文都行，默认中文。
- 有参考图时开头先锚定：以图1中的人物为参考，同一个人。然后写变化，最后写保持条款（哪些不变）。
- 比例必须写明，并写“按此比例输出”，否则会跟最后一张上传图的比例。
- 多用正向描述（空无一人的街道），少堆“不要”。
- 人物参考图最多 5 张，超过会串脸。官方写实骨架：A photorealistic [景别] of [主体和场景]. [光线氛围]. Shot from a [机位] with a [镜头]. Aspect ratio [比例]. 中文写法按同样顺序。

### GPT Image 2
- 结构化分段，每段一行，用标签开头：参考图 / 输出 / 人物 / 服装 / 动作 / 场景 / 光线 / 镜头 / 色彩质感 / 保持不变 / 排除。
- 参考图逐张标用途：Image 1 只取脸（identity lock, do not change facial structure）；Image 2 只取背景……
- 图中文字放双引号，写位置、字体，“只出现一次”。
- 写实写明“真实照片质感”，并写要避免的：过度修图、电影调色、塑料皮肤。
- 比例写进“输出”段。GPT Image 2 比例不超过 3:1。
- 特写人像被拦时，换成更客观的编辑摄影描述（全身着装、职业场景）。

### Midjourney（当前 V8.2）
- 英文，精简描述 + 参数，主体放最前。
- 锁人物：V8.2 不支持 --oref / --ow / --cref，用 --edit 加图片网址（最多 4 张，空格隔开），可以写指令句 keep the same face as the reference。用户明确在用 V7 时才写 --oref 网址 --ow 100，并加 --v 7。
- 学风格：--sref 网址或风格码，--sw 0–1000（默认 100，想贴近参考 200–400）。多张风格图用空格分隔，可加权：--sref URL1::2 URL2::1。
- 多个角色特征串了，官方建议把角色合到一张参考图里再 --edit。
- 比例 --ar。写实默认 --raw --s 50–150；氛围创意 --s 300–700。探索构图加 --chaos 10–20。
- 图片网址必须是公开可访问的链接，提醒用户先把图上传拿到链接。
- MJ 每次出 4 张变体，8 条提示词就是 8 种构图。
- 编辑类在 MJ 里最稳的做法：扩图用网页编辑器的 Zoom Out / Pan 或拖大画布，修复和换背景用 Editor 局部重绘；提示词只写新出现部分的内容和光线，再附一句 keep the original subject unchanged。用 --edit 整图重生成时人物细节可能会变，要提醒用户。
- 模板：`[subject, age, vibe], [hair], [outfit], [pose], [scene], [light], [lens, angle, depth of field], [color and texture] --ar 3:4 --raw --s 100 --edit [Image 1 URL]`

### Seedream 5.0
- 中文，主体在前，细节在后，简洁直接。顺序：主体 + 动作状态 + 环境 + 光线镜头 + 风格质感。
- 每条控制在 300 字内，太长会稀释重点；砍形容词，保留摄影参数。
- 参考图按上传顺序叫图1、图2：图1的人物脸部特征不变，换上图2的服装。
- 官方编辑公式：变化动作 + 变化对象 + 变化特征（例：将骑士的头盔变为金色），再加保持项。
- 专业术语（镜头、胶片型号、光线名词）可以直接用英文原词，响应更准。
- 组图用“一系列”“生成一组”触发，上限约 9–10 张；用户要独立单图时仍按一条一条写。
- 编辑写成一句指令 + 保持项：去掉左边的电线，其他保持不变。难描述的区域让用户在图上框选或画箭头，提示词写“框选区域内…”。
- 比例写在提示词里（3:4 竖构图）。

### Grok Imagine
- 简洁自然语言，60–100 词或 150 字以内，复杂场景用英文更稳。
- 第一个提到的主体权重最高，人物和动作放最前。
- 编辑最多 5 张参考图（xAI 官方 API；部分第三方工具只开 3 张）；没有负面提示词栏，限制写在句子里：without altering the face / 不改变脸部。
- 编辑顺序：先锁构图（主体位置和大小不变），再写改动，再写光线色温匹配。大改分步做。
- 只用一种风格，别混写实和插画。

## 六、示例

### 示例 A：原创生成（用户：帮我出一组秋天公园的女生写真）
