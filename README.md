# noahvisualsx-skill

noahvisuals（[@noahvisualsx](https://x.com/noahvisualsx)）的 AIGC 创作 skill 合集：生图提示词、视频提示词、照片复刻和 X 发图玩法。

每个 skill 都是一个文件夹，里面一个 `SKILL.md`。支持 Agent Skills 的工具（Claude、Claude Code、Codex 等）把文件夹放进 skills 目录就能用；其他 AI 可以直接把 `SKILL.md` 的内容贴进自定义指令。

## 目录

| Skill | 用途 |
|---|---|
| [image-prompt-master](skills/image-prompt-master/SKILL.md) | 生图提示词总控：原创、扩展、复刻、多图合成、编辑、电商，支持 GPT Image 2、Nano Banana Pro、Midjourney、Seedream 5.0、Grok Imagine |
| [midjourney-prompts](skills/midjourney-prompts/SKILL.md) | Midjourney V8.2 提示词：参数速查、Edit 锁脸、海报文字、迭代技巧 |
| [photo-expand-prompts](skills/photo-expand-prompts/SKILL.md) | 发人物照说扩展：8 张换动作，Nano Banana Pro + GPT Image 2 双版本，附主题文案 |
| [photo-pose-replicate-prompts](skills/photo-pose-replicate-prompts/SKILL.md) | 人物照复刻换姿势：4 张独立单图，附发帖文案 |
| [photo-style-replicate-prompts](skills/photo-style-replicate-prompts/SKILL.md) | 照片风格复刻、换主体（换花、换物件） |
| [video-replicate-prompts](skills/video-replicate-prompts/SKILL.md) | 短视频拆解复刻：抽帧分析，输出首帧图、图生视频时间线和负面词 |
| [omni](skills/omni/SKILL.md) | Google Gemini Omni 视频提示词：参考图锁角色、分秒节拍、对话式修改 |
| [x-carousel-split](skills/x-carousel-split/SKILL.md) | X 横滑拼图（三联屏）：竖切长条、白缝预览、构图和比例建议 |
| [fabric-texture-prompt-cn](skills/fabric-texture-prompt-cn/SKILL.md) | 提升衣服质感：质感五层拆解、换衣服保留质感、按 Seedream / ChatGPT / Nano Banana / Midjourney 改写 |
| [lofi-snapshot-prompt-cn](skills/lofi-snapshot-prompt-cn/SKILL.md) | 豆包 / Seedream 风格的古早 CCD 随手拍真人写真提示词，含图生视频动作提示词 |
| [video-outfit-prompt-cn](skills/video-outfit-prompt-cn/SKILL.md) | 拆解穿搭视频或照片里的整套穿搭，写成生图提示词，让原创角色穿上同款 |
| [doubao-prompt-harvest](skills/doubao-prompt-harvest/SKILL.md) | 用 Mac 的 iPhone 镜像操控手机豆包，批量整理「AI 创作 · 发现」作品的做同款提示词 |
| [selfie-pushin-music-video](skills/selfie-pushin-music-video/SKILL.md) | 手持前置自拍、怼脸跳切、踩点音乐的竖屏短视频 |
